# Project Name

Smart Car Parking Fog and Edge Simulator

## Project Overview

The project developed the ifogsim smart car parking application with implementation of Pareto Optimization framework for reducing energy consumption.

## Getting Started

import the project into IDE (eclipse)
include all required jar files from the /jar folder 
build the project successfully
run smartcarparking.java class for running the simulation successfully.

### Prerequisites

Jdk 8 or later
Eclispe IDE or IntelliJ IDE
dependecies JAR files included in /jar folder (like jMetal JARs)
